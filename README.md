## Projeto em destaque: Dashboard de Vendas

Relatório em **Power BI** para explorar o desempenho comercial, acompanhar indicadores e comparar resultados de lojas, regiões e vendedores.

**[Baixar o arquivo Power BI (.pbix)](Projeto_Vendas.pbix?raw=true)**

### Perguntas que orientam a análise

- Como a receita evolui ao longo do tempo?
- Quais lojas e regiões concentram o resultado?
- Como os vendedores se comparam em receita, lucro e volume de vendas?
- Qual é a relação entre margem, descontos e ticket médio?
- Como categorias de produtos e formas de pagamento participam das vendas?

### Páginas do relatório

| Página | Conteúdo |
| :--- | :--- |
| **Vendas gerais** | Indicadores comerciais, comparação de lojas, análise regional e evolução das vendas |
| **Vendedores** | Análise do desempenho dos vendedores e comparação de resultados |

Os dados deste projeto são fictícios e são utilizados para demonstração no portfólio.

### Ferramentas e conceitos

- **Power BI Desktop:** construção do relatório e visualização dos dados.
- **Power Query:** preparação de dados a partir de arquivos CSV.
- **DAX:** medidas de receita, lucro informado, margem, vendas e ticket médio.
- **Modelo de dados:** vendas relacionadas a clientes, produtos, lojas, vendedores e calendário.
- **Visuais personalizados:** componentes incorporados ao arquivo para a apresentação das análises.

### Como explorar

1. Baixe o arquivo `Projeto_Vendas.pbix` pelo link acima.
2. Abra-o no Power BI Desktop.
3. Navegue pelas páginas **Vendas gerais** e **Vendedores** e utilize os filtros disponíveis.

O GitHub disponibiliza o download do arquivo; a interação com o dashboard acontece no Power BI Desktop. O PBIX inclui um modelo de dados incorporado. Para atualizar as fontes, será necessário ajustar os caminhos dos CSVs no Power Query e ter acesso aos arquivos de origem, que não estão incluídos nesta publicação.

### Leitura dos indicadores

O indicador de lucro representa o valor informado na base; não é apresentado como lucro líquido contábil. A margem considera lucro agregado dividido pela receita, e o ticket médio considera receita dividida pela quantidade distinta de vendas.
